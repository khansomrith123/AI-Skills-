# Web Development Skill

## Purpose

This skill provides AI agents with specialized knowledge for building professional websites and web applications. It covers planning, frontend/backend, APIs, databases, authentication, responsive design, accessibility, SEO, performance, security, testing, deployment, and maintenance.

## When to Use

Use this skill when:
- Building a new website, landing page, or web application
- Fixing bugs in web code (HTML/CSS/JS/TS, frontend/backend)
- Improving responsiveness, accessibility, performance, or SEO
- Adding features like auth, forms, APIs, or database integration
- Refactoring existing web projects
- Planning web architecture or deployment

## When NOT to Use

Do not use for:
- Native mobile apps (iOS/Android)
- Game development
- Desktop applications
- PCB/electronics design
- Pure CLI tools with no web interface

## Key Principles

- Requirements-driven, simplicity first
- Security by default
- Accessibility and responsiveness
- Technology selection based on fit, not popularity
- Engineering honesty (explicit status of what was done)
- Understand → Plan → Build → Test → Review → Deliver

## Quick Start

An AI agent loads this skill by reading `SKILL.md` completely, then applies its workflows to the task. The skill teaches how to think about web development while respecting the global priority system.

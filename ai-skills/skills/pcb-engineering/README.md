# PCB Engineering Skill

## Purpose

This skill provides AI agents with specialized knowledge for professional PCB design. It covers requirements, schematic capture, PCB layout, design rules, DFM, signal/power integrity, grounding, thermal considerations, BOM, Gerber generation, and strict engineering honesty about design states.

## When to Use

Use when:
- Designing PCBs (schematic + layout)
- Selecting components for PCB designs
- Planning routing, stackup, power/grounding
- Preparing manufacturing files (Gerbers, drill, BOM)
- Reviewing PCB designs for issues
- Addressing DFM, signal integrity, or thermal concerns

## When NOT to Use

Do not use for:
- Pure circuit theory without PCB implementation
- Firmware development
- Mechanical enclosure/CAD beyond board outline
- Software/web development
- Physical testing execution beyond planning

## Key Principles

- Safety first
- Requirements-driven
- DFM-aware, manufacturable designs
- Clear distinction: Designed/Reviewed/Simulated/Tested/Verified/Manufactured/Validated
- Engineering honesty is non-negotiable
- Understand → Plan → Build → Review → Deliver (Test conceptually)

## Critical: Engineering Honesty

Never claim physical testing, simulation, manufacturing, verification, security audit, or electrical validation unless actually performed. Explicitly state what was done.

# Website Agent Example

## Scenario

User: "Build me a simple personal portfolio website"

## Expected Behavior

1. **Analyze request** → Identify as web project
2. **Discover skills** → Match `web-development` via activation
3. **Load skill** → Read `skills/web-development/SKILL.md` completely
4. **Understand** → Clarify goals, sections needed, tech, deployment
5. **Plan** → Structure, tech selection (requirement-based), pages, styling
6. **Build** → Create HTML/CSS/JS, responsive, semantic, accessible
7. **Test** → Validate responsive, basic functionality, links
8. **Review** → QA against web-development checklist
9. **Deliver** → Honest status (Designed/Implemented, Tested if performed)

## Skill Used

- Primary: `web-development` (v1.0.0)

## Notes

Agent should choose minimal tech (e.g., vanilla HTML/CSS/JS) unless requirements justify framework. Must not claim unperformed testing.
